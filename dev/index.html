MFAOA.jl

MFAOA.jl solves binary quadratic programs without constraints: it minimizes or maximizes

\[f(x) = x^\top Q x + c^\top x + \text{constant}, \qquad x \in \{0, 1\}^n .\]

This problem class is known as UBQP (unconstrained binary quadratic programming) or QUBO. Max-Cut is a well-known example. MFAOA runs a fixed number of steps, 1000 by default, and returns a solution without a proof that no better one exists.

Installation

MFAOA.jl needs Julia 1.10 or later. It is not in the General registry yet, so add it from its repository:

using Pkg
Pkg.add(url = "https://github.com/Quicopt/MFAOA.jl")

The example below also needs JuMP: Pkg.add("JuMP").

Example

From JuMP, pass MFAOA.Optimizer to the model:

using JuMP, MFAOA

model = Model(MFAOA.Optimizer)
@variable(model, x[1:3], Bin)
@objective(model, Min, 2x[1] * x[2] - 3x[2] * x[3] - x[1] - x[2] + x[3])
optimize!(model)

println("status:    ", termination_status(model))
println("solution:  ", round.(Int, value.(x)))
println("objective: ", objective_value(model))
status:    LOCALLY_SOLVED
solution:  [0, 1, 1]
objective: -3.0

Of the eight assignments of x, (0, 1, 1) has the smallest objective value, -3. The status LOCALLY_SOLVED says that MFAOA returned a solution, without a proof of optimality.

Reference

MFAOA implements the mean-field approximate optimization algorithm of

A. Misra-Spieldenner, T. Bode, P. K. Schuhmacher, T. Stollenwerk, D. Bagrets and F. K. Wilhelm, Mean-field approximate optimization algorithm, PRX Quantum 4, 030335 (2023), doi:10.1103/PRXQuantum.4.030335.
